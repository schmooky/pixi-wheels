# Getting help with pixi-wheels

- **A question**: open a [GitHub Discussion](https://github.com/schmooky/pixi-wheels/discussions).
- **A bug**: file a [bug report](https://github.com/schmooky/pixi-wheels/issues/new?template=bug_report.yml). A headless `createTestWheel` reproducer is the fastest path to a fix.
- **A feature idea**: a [feature request](https://github.com/schmooky/pixi-wheels/issues/new?template=feature_request.yml), or a Discussion first.
- **A security issue**: follow [SECURITY.md](./SECURITY.md). Do not open a public issue.
- **Contributing**: [CONTRIBUTING.md](./CONTRIBUTING.md) and [AGENTS.md](./AGENTS.md).
